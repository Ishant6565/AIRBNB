# Airbnb Clone

Next.js Airbnb-style stays browser with responsive listing cards, category browsing, room details, search flow, and persistent deep-black dark mode.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

Import this repository into Vercel. The framework is detected as Next.js and the default build command is `npm run build`.
